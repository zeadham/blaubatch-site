## Open issues to resolve before print

1. **Office address conflict.** The catalogue says *Arkan Plaza, Building 4, Sheikh Zayed*; the September RFQs say *Office 1–C2, Building 3, Polygon, SODIC, Sheikh Zayed*. The new flyer and sheet show only phone, email and website. Confirm the current office before the catalogue is reprinted.
2. **Catalogue needs a refresh.** It is a 15-page product list with no sales story. Add: a "One Source. Full Spectrum." opening spread, the facility photo, an application guide, and the Coraplast partnership page. Fix "CaCO" (the subscript 3 is missing in the filler tables). The printing RFQ says 23 pages, but the current file is 15, so update the RFQ with the final count.
3. **QR code destination.** All QR codes point to `https://www.blaubatch.com/campaign`. That page couldn't be reached from this environment, so check that it is live and links to the catalogue and TDS downloads. Consider a dedicated `/afroplast` page with UTM tracking.
4. **Arabic copy.** Drafted, not professionally reviewed. Per Brand Guidelines §14.4, the Arabic translation of the tagline "Full-Spectrum Masterbatch Solutions" is still pending approval, so the Arabic side uses only the campaign line "One Source. Full Spectrum." Coraplast is referred to as "our European partner" with its logo, so no Latin words sit inside Arabic sentences.
5. **Dosage ranges.** Section 2 of the savings sheet gives typical industry starting points. The technical team must confirm them against our own grades before printing.
6. **Coraplast approval.** The flyer uses the Coraplast logo and the "Coraplast range" wording. Both need Coraplast's sign-off, the same as the press release.
7. **Photo rights.** `BlauBatchFacility.jpg` carries a photographer copyright (sherifalyamany.com). Confirm the licence covers print before using it in the catalogue.
8. **Grade counts on the flyer** come from the current catalogue: filler 8 · black 15 · white 11 · UV 5 · additives 17. Update them if the range changes.

## Files in this folder

- `flyer_A5.html` / `flyer_A5.pdf`: A5 flyer, page 1 English, page 2 Arabic
- `filler_savings_sheet_A4.html` / `filler_savings_sheet_A4.pdf`: A4 savings calculator
- `previews/`: PNG previews of each page
- `assets/`: logos, QR code and local font files (fonts are bundled so the PDFs render the same on any machine)

To re-render the PDFs after editing the HTML, open the HTML in Chrome, choose Print, set margins to None, turn on Background graphics, and save as PDF. The PDFs here were made that way, but they are RGB screen proofs. Ask the printer for CMYK conversion and 3 mm bleed on the final files.
