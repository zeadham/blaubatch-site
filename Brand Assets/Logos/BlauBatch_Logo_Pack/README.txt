WHICH FILE DO I USE?
  SVG  → web, apps, print, anything that scales (preferred)
  PNG  → PowerPoint, Word, email, social media (transparent background)
  JPG  → master reference only

FOLDERS
  01_Primary          B mark on navy square. Default logo for most uses.
  02_Logomark         B mark without the square. Navy or dark backgrounds ONLY.
  03_Horizontal       Mark + BLAU BATCH. Headers, letterheads, email signatures, web nav.
                        _LightBG = navy text for white backgrounds
                        _DarkBG  = white text for navy backgrounds
  04_Arabic           Mark + بــلاو بــاتش (Cairo Black, right-to-left). Arabic-language materials.
  05_Wordmark         BLAU BATCH text only (Inter Black). When the mark already appears nearby.
  06_Mono             One-colour versions for single-ink print, embossing, engraving.
  07_Favicon_AppIcon  Browser tab icons (16/32/48) and app/social icons (180/512).
  08_Boxed            Wordmark in Box (§3.1.1). Navy border on white, white border on navy.
  09_Coraplast        Partner logo: with slogan, horizontal without slogan, symbol only.
  10_CoBrand          Blau Batch | Coraplast lockup. White or #F7F8FC backgrounds only.

RULES
  • Clear space on all sides = height of the "B" (co-brand: 2× the "B").
  • Minimum size: 120 px wide on screen, 25 mm wide in print.
  • Do not stretch, rotate, recolour, outline, or add shadows or effects.
  • Do not place on busy photos without a solid navy or white backing.
  • Coraplast files are raster — request vector artwork from Coraplast for print.
  • Only use the approved brand colours:
      Deep Navy #141B3E · Steel Blue #23447A · Sky Blue #2B8DD0 · White #FFFFFF
